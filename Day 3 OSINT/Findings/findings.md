Findings
Objective
Perform introductory OSINT and reconnaissance activities using publicly available information sources.

Finding 1
WHOIS lookups successfully identified publicly available domain registration information.

The activity demonstrated how ownership and registration details can be discovered through open sources.

Severity: Informational

Finding 2
DNS enumeration successfully revealed publicly accessible DNS records.

The identified records provided insight into how domain services are configured.

Severity: Informational

Finding 3
Technology fingerprinting successfully identified web technologies associated with target websites.

This activity highlighted how publicly exposed technologies can often be discovered without authentication.

Severity: Informational

Finding 4
OSINT techniques provided valuable information using only publicly available sources.

No privileged access or intrusive testing was required during information collection.

Severity: Informational

Conclusion
The exercise demonstrated the value of reconnaissance and OSINT in gathering information before any security assessment begins.
